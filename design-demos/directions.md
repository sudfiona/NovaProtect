# NovaProtect · 客户端 + 官网 重设计 · 三方向

**受众**：独立开发者 / 个人开发者 / 小团队做 Windows 软件的年轻工程师（18–30）
**场景**：保护自己写的 EXE（工具、游戏外挂客户端、商用小软件），要好看、好用、不土
**核心信息**：代码保护可以很酷；构建前看得见生效项；无需账号
**情感基调**：轻快、有主见、带点潮流感，但不是儿童玩具
**输出格式**：官网首页（HTML 可预览）+ 客户端壳层视觉规范（同色板/组件语言，后续落到 WinUI）

---

## 方向 A · Liquid Glass「液态玻璃」
- **逻辑**：延续 HyperOS 磨砂玻璃，但推向更年轻的「液态玻璃 + 极光流体」——大圆角、彩色折射、bento 卡片、微交互
- **主角素材**：首屏巨大 3D 玻璃盾 / 极光流体渐变球（CSS/程序化材质）
- **骨架**：Hero 大标题 + 流体球 → Bento 功能宫格 → 客户端界面 mock 悬浮卡片
- **form 来自内容**：保护 = 一层「看得见的玻璃壳」，代码在壳里被折射得读不懂
- **参照气质**：Apple Liquid Glass / 现代 SaaS 官网 / HyperOS 柔光
- **配色**：品牌蓝紫 `#2E7CF6 #7B61FF` + 浅冰底 `#F3F7FF` + 少量青柠点缀

## 方向 B · Neo Pop「新波普」
- **逻辑**：Z 世代玩得开——撞色、厚描边、贴纸感、大字报、不规则圆角贴纸卡
- **主角素材**：盾牌贴纸 / 闪电 / 代码碎片贴纸（CSS 描边插画风）
- **骨架**：超大标题 + 贴纸拼贴 hero → 功能卡像贴纸墙 → CTA 大按钮贴纸
- **form 来自内容**：保护自己写的软件 = 「贴上我的徽章」，像贴纸/印章一样有仪式感
- **参照气质**：Figma 社区新波普 / 独立开发者落地页 / Y2K 包装纸
- **配色**：电光紫 `#7B61FF` + 荧光绿 `#B8FF3C` + 奶油底 `#FFF8E7` + 黑描边

## 方向 C · Dark Lab「暗色实验室」
- **逻辑**：黑客工具审美但更精致——深空黑、等宽字、终端绿/霓虹青、网格线、数据仪表
- **主角素材**：代码 diff 卡片 / 终端窗口 / 扫描线仪表（CSS）
- **骨架**：暗色 Hero + 大等宽标语 → 功能清单像命令面板 → 客户端模拟终端面板
- **form 来自内容**：保护是「逆向读不懂」——用不可读的 diff/乱码流体做主视觉
- **参照气质**：Linear 暗色 / Vercel / 安全工具 landing（更潮的 GitBook）
- **配色**：`#0B0F1A` 底 + 霓虹青 `#22D3EE` + 紫 `#A78BFA` + 终端绿 `#4ADE80`
