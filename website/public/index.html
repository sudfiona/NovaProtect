Product surface

从项目配置到发布前检查

官网提供客户端下载与更新日志；保护能力全部在本地客户端内完成。

01

可信对象编辑

只展示真实 SDK marker 区域，不把任意符号、导出或反编译结果伪装成函数。

02

请求 / 生效 / 冲突

统一模型记录请求区域、生效区域与冲突项，导出前即可核对差异。

03

发布前检查

虚拟化、混淆、加密与校验项在打包前一次跑完，问题就地定位。

Release flow

官网只负责分发客户端

安装包与更新说明发布在 GitHub Releases，客户端启动时自动检查更新。

04

公开下载

无需账户，从 GitHub Releases 直接下载当前版本安装包，不经过本站中转。

05

自动更新

客户端按最低可用版本判断是否强制更新，完整发布历史就是 Releases 列表。

06

独立发布

客户端从 Releases 读取版本与更新说明，官网是纯静态页面，两者的发布互不牵制。
