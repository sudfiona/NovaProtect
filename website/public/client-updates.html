正式版2026-10-20

客户端 2.3.0

# 本轮更新总结

## 一、更稳定的硬件因子（一机一码增强）

原来只有 CPUID + 卷序列号，重装系统/换盘会失效。现在升级为三因子：

| 因子 | 稳定性 | 说明 |
| ----------- | --- | --------------------------------------------------------------------- |
| CPUID | 型号级 | 基础指纹 |
| 卷序列号 | 安装级 | 重装会变 |
| MachineGuid | 主板级 | `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid`，重装系统/换盘不变，是主要稳定性锚点 |

- 打包机（`main.cpp`）和运行时（`prot64.c`）两边算法严格一致：都从注册表读 MachineGuid、逐 UTF-16 code unit 拆字节喂 FNV-1a，再与卷序列号、CPUID 串联。
- 本机 ID 已从 `55DBC795...` 变为三因子 `AB5FADA2...`，`-activation auto` 绑定 + 本机运行通过。

## 二、反沙箱作为独立保护功能（重点反微步云沙箱）

之前反沙箱逻辑只在运行时里、UI 没暴露。本轮：

1. UI 独立开关：保护页新增三个 ToggleSwitch：
- 「反沙箱检测（重点反微步云沙箱）」
- 「反内存转储」
- 「交互桌面环境自检」
- 已接线到模型 → CLI 参数 → 构建计划 → 能力矩阵。
2. 反沙箱检测增强（`np_sandbox_score`）：
- 新增已知沙箱模块硬信号（`dbghelp`/`dbgcore`/`dbgeng`/`procmon`/`frida`/`sandbox` 等）计分。
- 新增睡眠压缩检测：对比 RDTSC 周期与 `GetTickCount64` 墙钟时间，沙箱压缩时间会暴露异常比值。
- 新增桌面分辨率 + 环境模板名检测（`Win*`/`Admin*`/`User*` 等微步沙箱常见临时账户名）。
- 保留原有的 CPUID 厂商位、CPU 数、内存、RDTSCP 时序、核掩码。
3. 验证：`-sandbox-guard -anti-dump -env-check` 打包后 `NPP1 flags=0xEA9`，bit9/10/11 全部置位；完整回归 ALL PASS。
4. 官网 SDK 文档：新增「反沙箱 / 反转储 / 环境自检」章节。

客户端 2.2.7

version.ps1 编码缺陷：文件是 UTF-8 无 BOM，PowerShell 5.1 在中文 Windows 按 GBK 解析 → 中文注释变乱码写进 version.iss → 安装包描述乱码 → 网站 release notes 乱码。已给 3 个含中文的 .ps1 补 UTF-8 BOM
