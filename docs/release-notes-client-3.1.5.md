# NovaProtect 客户端 3.1.5 更新日志

发布类型：客户端（桌面程序）· 版本 `3.1.5` · 2026-11-22

本文是面向使用者的更新说明，可直接作为 GitHub Release 正文使用。实现细节见
`CHANGELOG.md` 的 `## 3.1.5` 一节。

---

## 一句话概括

3.1.5 只修了两个客户端外观问题，引擎一点没动：主题切换条不再是椭圆，打开设置页
也不会再把界面改回玻璃。

---

## 修了什么

**主题按钮那条轨道还是椭圆的**

3.1.4 把三套主题重写完之后，按钮本身已经是圆角矩形了，但外面包着的那层轨道圆角
还是 999，整条看起来像一颗胶囊，挺丑的。这版按主题给了正常圆角——玻璃 12、波普 4、
实验室 6——跟官网一致。

**切到波普，一点设置就变回玻璃**

这个更烦：主题明明已经选了波普或实验室，一点「设置」，整页又变回玻璃特效，下拉框
却还显示着你选的那个。

原因是设置页在 XAML 里写死了默认选中第一项（玻璃）。页面一构造，`SelectionChanged`
就触发了，主题被强行切成 glass，配置文件也一起写坏了。现在构造时只把下拉框对齐到
当前主题、不真正执行切换；如果下拉框和当前主题本来就一致，直接跳过。

## 怎么验的

客户端 Release 构建 0 警告 0 错误。手动走了一遍：切到波普或实验室 → 打开设置 →
主题和下拉框都保持原样；顶栏主题条是圆角矩形，不再是胶囊。
